# @jupyterlab/codeeditor

A JupyterLab package which defines an abstract interface to a code editor,
which is used in many places in the application, including [cells](https://github.com/jupyterlab/jupyterlab/tree/main/packages/cells)
and the [file editor](https://github.com/jupyterlab/jupyterlab/tree/main/packages/fileeditor).
