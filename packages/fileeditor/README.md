# @jupyterlab/fileeditor

A JupyterLab package which provides a text editor. The default text editor wraps
a [codemirror](https://github.com/jupyterlab/jupyterlab/tree/main/packages/codemirror) instance, but others may be substituted by
implementing the [@jupyterlab/codeeditor](https://github.com/jupyterlab/jupyterlab/tree/main/packages/codeeditor) interface.
