# Vendor Console — إدارة الموردين (المرحلة الأولى)

تطبيق Google Apps Script لإدارة الموردين والمدفوعات، مبني على نفس هيكل وتنسيق تطبيق العملاء.

## الملفات
| الملف | الوصف |
|---|---|
| `Code.gs` | الخادم (Google Sheets كقاعدة بيانات) |
| `Index.html` | الصفحة الرئيسية |
| `Script.html` | واجهة المستخدم |
| `appsscript.json` | إعدادات المشروع |
| `Styles.html` | **يُنسخ كما هو من تطبيق العملاء دون تعديل** (نفس الخطوط والألوان) |

## التشغيل
1. أنشئ Google Sheet جديداً ← Extensions ← Apps Script.
2. انسخ الملفات أعلاه + `Styles.html` من التطبيق القديم.
3. شغّل `setup()` مرة واحدة (أو `loadDemoData()` لبيانات تجريبية).
4. Deploy ← New deployment ← Web app.
5. الدخول الافتراضي: `admin` / `admin123`.

## الاتجاه المحاسبي (ذمم دائنة)
- فاتورة المورد = **دائن** (تزيد المستحق للمورد).
- الدفعة / الإشعار = **مدين** (تُنقص المستحق).
- الرصيد = دائن − مدين.
